 **Assignment 8.3 — Magazine Layout Using Grid Areas**.

To satisfy all requirements of this assignment, the project is structured into two clean, production-ready files:

1. **`style.css`** (External stylesheet implementing CSS Grid with named template areas, proportional column sizing, and magazine styling)
