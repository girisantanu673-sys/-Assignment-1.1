**Assignment 8.5 — CSS Grid Mini-Project**.

To build a comprehensive, high-performance photo-gallery website meeting every strict rubric rule, the project is structured into two clean files:

1. **`style.css`** (External stylesheet implementing CSS Grid with named template areas, `repeat()`, `minmax()`, `fr` units, and overflow prevention)
2. **`index.html`** (Complete photo-gallery webpage featuring a header, named grid layout, 8 responsive photo cards, a featured showcase section, and a footer)
