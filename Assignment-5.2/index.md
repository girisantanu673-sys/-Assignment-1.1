                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    ### Short Explanation of Selectors Used (For Submission)

                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    #### 1. Universal Selector (`*`)

                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    * **Usage:** `* { box-sizing: border-box; margin: 0; padding: 0; }`
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    * **Purpose:** Targets every element on the webpage to eliminate default browser spacing and establish a consistent box-sizing model.

                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    #### 2. Element Selector (`body`, `p`)

                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    * **Usage:** `p { font-size: 1rem; color: #475569; }`
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    * **Purpose:** Directs styling to specific HTML tag names across the entire document without requiring class names.

                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    #### 3. Class Selector (`.card`, `.container`, `.card-grid`)

                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    * **Usage:** `.card { background-color: #ffffff; border-radius: 10px; }`
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    * **Purpose:** Applies reusable styles to multiple elements across the page (e.g., all 3 card containers share `.card`).

                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    #### 4. ID Selector (`#hero-section`, `#demo-text`)

                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    * **Usage:** `#hero-section { border: 2px solid #2563eb; }`
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    * **Purpose:** Targets a single, unique element on the webpage. It carries higher specificity than class and element selectors.

                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    #### 5. Grouping Selector (`h1, h2, h3`)

                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    * **Usage:** `h1, h2, h3 { font-weight: 700; letter-spacing: -0.5px; }`
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    * **Purpose:** Combines multiple selectors with commas to apply identical CSS styles without repeating code.

                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    #### 6. Specificity & Cascade Result

                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    * **Observation:** When two rules target the same paragraph (`<p id="demo-text" class="special-text">`):
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    1. The general `p` selector has a low specificity score `(0,0,0,1)`.
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    2. The `.special-text` class selector has a higher score `(0,0,1,0)`.
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    3. The `#demo-text` ID selector has the highest score `(0,1,0,0)`.


                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    * **Result:** The browser resolves conflict by applying the ID selector rule (turning the text red), demonstrating that higher-specificity selectors always override lower-specificity selectors in the cascade order.
