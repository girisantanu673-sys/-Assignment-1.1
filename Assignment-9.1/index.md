**Assignment 9.1 — Convert a Desktop Page into a Mobile-First Layout**.
 **mobile-first approach**. The base CSS rules target mobile screens, while two distinct breakpoints (`min-width: 768px` for tablets and `min-width: 1024px` for desktops) enhance the layout progressively.

The project is structured into two clean files:

1. **`style.css`** (Mobile-first stylesheet with media queries and breakpoints)
2. **`index.html`** (Webpage verified with the correct viewport meta tag)
