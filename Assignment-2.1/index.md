1. index.html Code
Create a file named index.html in your project folder and paste the following well-structured and indented code into it:

HTML
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
        <meta name="viewport" content="width=device-width, initial-scale=1.0">
            <title>My First Webpage</title>
            </head>
            <body>

                <!-- Main heading for the webpage -->
                    <h1>Welcome to My First Webpage</h1>

                        <!-- Subheadings dividing the page content -->
                            <h2>1. Introduction</h2>
                                <p>This is my very first HTML webpage created as part of my web development practice.</p>

                                    <h2>2. Key Concepts Learned</h2>
                                        <p>I am learning how to structure content using proper HTML tags, headings, and comments.</p>

                                            <h2>3. Future Goals</h2>
                                                <p>Soon, I will learn CSS styling and JavaScript to make my websites interactive and visually appealing.</p>

                                                </body>
                                                </html>
                                                2. Steps to Complete the Assignment
                                                Save the File: Save the code above inside your project folder as index.html.

                                                Open in Browser: Right-click the index.html file and open it in your preferred browser (or use Live Server in VS Code).

                                                Verify: Check that the browser tab title reads "My First Webpage" and that your main heading (<h1>) and three subheadings (<h2>) are correctly rendered on the screen.
