**Assignment 3.1 — Two-Page Website with Working Links**.
you need to create two separate HTML files (index.html and about.html) in the same folder and link them together using anchor tags (<a>), along with a secure external link.

### 1. `index.html` (Home Page)

Save this file as `index.html`:

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
        <meta name="viewport" content="width=device-width, initial-scale=1.0">
            <title>Home - Shalini Gangwar</title>
            </head>
            <body>

                <!-- Navigation Bar -->
                    <nav>
                            <a href="index.html">Home</a> | 
                                    <a href="about.html">About</a> | 
                                            <a href="https://github.com" target="_blank" rel="noopener noreferrer">GitHub (External)</a>
                                                </nav>

                                                    <hr>

                                                        <!-- Home Page Content -->
                                                            <header>
                                                                    <h1>Welcome to My Website</h1>
                                                                            <p>Hello! I am <strong>Shalini Gangwar</strong>, a Computer Science and Engineering student exploring web development.</p>
                                                                                </header>

                                                                                    <main>
                                                                                            <h2>Home Page Overview</h2>
                                                                                                    <p>This is the home page of my two-page web project. You can use the navigation links above to visit my About page or check out an external website securely in a new tab.</p>
                                                                                                        </main>

                                                                                                            <footer>
                                                                                                                    <hr>
                                                                                                                            <p><small>&copy; 2026 Shalini Gangwar. All rights reserved.</small></p>
                                                                                                                                </footer>

                                                                                                                                </body>
                                                                                                                                </html>

                                                                                                                                ```
