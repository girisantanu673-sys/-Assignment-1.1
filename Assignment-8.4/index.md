**Assignment 8.4 — Dashboard with Grid and Flexbox**.

**CSS Grid** for the macro-level page layout (header, sidebar, main content) and **Flexbox** for the micro-level component layouts (statistic cards and internal alignments).

The project is structured into two clean files:

1. **`style.css`** (External stylesheet combining CSS Grid for the outer container and Flexbox for inner cards, tables, and headers)
2. **`index.html`** (Dashboard webpage structuring the header, sidebar, 4 statistic cards, and a recent activity table)
